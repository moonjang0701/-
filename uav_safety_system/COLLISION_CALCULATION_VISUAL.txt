🔍 충돌 검사 상세 알고리즘
══════════════════════════════════════════════════════════════════════════════

for t in [0, 0.1, 0.2, ..., 60.0]:  ← 600번 반복
    │
    ├─ Step 1: 현재 비행 중인 UAV 찾기
    │   │
    │   ├─ UAV #1: start=5.2, end=32.8 → 5.2 ≤ t ≤ 32.8? 
    │   │   └─ YES → 위치 계산 p_1(t)
    │   │
    │   ├─ UAV #2: start=12.5, end=45.2 → 12.5 ≤ t ≤ 45.2?
    │   │   └─ YES → 위치 계산 p_2(t)
    │   │
    │   └─ ... (20대 모두 검사)
    │
    ├─ Step 2: 모든 쌍 간 거리 계산
    │   │
    │   ├─ d(#1, #2)  = ||p_1(t) - p_2(t)||
    │   ├─ d(#1, #3)  = ||p_1(t) - p_3(t)||
    │   ├─ d(#1, #4)  = ||p_1(t) - p_4(t)||
    │   └─ ...
    │       총 C(n,2) = n×(n-1)/2 개 쌍
    │       최대 C(20,2) = 190개 거리 계산
    │
    └─ Step 3: 충돌 판정
        │
        └─ if any d_ij < 50m:
               return COLLISION ⚠️

if no collision found in all 600 time points:
    return NO_COLLISION ✓

══════════════════════════════════════════════════════════════════════════════
📐 수학적 수식
══════════════════════════════════════════════════════════════════════════════

1. UAV i의 시간 t에서 위치:

   p_i(t) = p_i^start + α(t) × (p_i^end - p_i^start) + ε_i(t)

   where:
     α(t) = (t - t_i^start) / (t_i^end - t_i^start)  ← 진행률 [0, 1]
     ε_i(t) ~ N(0, σ²)                                ← GPS 오차, σ=5m


2. UAV i와 j 간 거리:

   d_ij(t) = ||p_i(t) - p_j(t)||

           = √[(x_i - x_j)² + (y_i - y_j)² + (z_i - z_j)²]


3. 충돌 조건:

   Collision(t) ⟺ ∃ i, j (i≠j) : d_ij(t) < d_safe

   where d_safe = 50m = 0.05km


4. 슬롯 충돌 지시자:

   I_slot = {1  if ∃ t ∈ [0,60] : Collision(t)
            {0  otherwise


5. 슬롯 충돌 확률:

            N
           ∑ I_slot^(k)
           k=1
   P_slot = ─────────────
                N

   where:
     N = 1000 (시행 횟수)
     I_slot^(k) = k번째 시행의 충돌 여부 {0, 1}


6. 전체 충돌 확률 (8개 슬롯):

   P_overall = 1 - ∏(1 - P_slot_i)
                   i=1

             ≈ 1 - (1 - P_avg)^8  ← 평균 사용 시

✅ 핵심 요약
══════════════════════════════════════════════════════════════════════════════

한 슬롯 충돌 확률 = (충돌 발생 횟수) / (전체 시행 횟수)

예시:
  - 1000번 시뮬레이션 실행
  - 188번 충돌 발생
  - P_slot = 188 / 1000 = 18.8%

계산 과정:
  1. 1000번 반복
  2. 각 시행마다:
     - 20대 UAV 생성 (10출항 + 10입항)
     - 60분 동안 6초마다 위치 계산 (600회)
     - 모든 UAV 쌍 거리 검사 (최대 190쌍)
     - 거리 < 50m → 충돌
  3. 충돌 횟수 집계
  4. 확률 = 충돌 횟수 / 1000
