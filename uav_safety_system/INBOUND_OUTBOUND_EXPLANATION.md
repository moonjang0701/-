---

## ✅ 수정 완료!

### 이전 구현 (잘못됨):
```
❌ 20대가 모두 출항만 (base → 목적지)
   - 현실성 부족
   - 입항 트래픽 미고려
```

### 현재 구현 (올바름):
```
✅ 20대 = 10대 출항 + 10대 입항
   - 출항 (10대): base → 목적지
   - 입항 (10대): 목적지 → base
   - 각각 독립적인 UAV
```

## 🔬 독립성 검증

### 이론적 예측:
```python
p_slot = 0.1832  # 평균 슬롯 충돌 확률
p_overall = 1 - (1 - 0.1832)^8
          = 1 - (0.8168)^8
          = 1 - 0.1951
          = 0.8049
          = 80.49%
```

## 💡 왜 충돌 확률이 증가했나?

### 1. 트래픽 밀도 증가
```
이전: 10대 (모두 같은 방향)
현재: 20대 (10대 출항 + 10대 입항)
```

### 2. 교차 경로 증가
```
출항: base → 다양한 목적지 (방사형)
입항: 다양한 출발지 → base (집중형)

→ 기지 근처에서 경로 교차 가능성 ⬆️
```

### 3. 더 현실적인 시나리오
```
실제 배송 센터:
- 동시에 출발하는 드론
- 동시에 돌아오는 드론
- 공역 내 밀도가 높음
```

## 🎓 구현 세부사항

### UAVFlight 클래스:
```python
@dataclass
class UAVFlight:
    """단일 UAV 편도 비행 정보"""
    uav_id: int
    start_time: float        # 출발 시간 (분)
    end_time: float          # 도착 시간 (분)
    start_pos: np.ndarray    # 출발 위치 [x, y, z] (km)
    end_pos: np.ndarray      # 도착 위치 [x, y, z] (km)
    flight_type: str         # "outbound" or "inbound"
```

### 비행 생성 로직:
```python
def create_time_slot_flights(self, num_uavs: int):
    flights = []
    
    # 출항 UAV (절반)
    num_outbound = num_uavs // 2
    for i in range(num_outbound):
        # base → random_destination
        flight = UAVFlight(
            ...,
            start_pos=base,
            end_pos=destination,
            flight_type="outbound"
        )
    
    # 입항 UAV (절반)
    num_inbound = num_uavs - num_outbound
    for i in range(num_inbound):
        # random_origin → base
        flight = UAVFlight(
            ...,
            start_pos=origin,
            end_pos=base,
            flight_type="inbound"
        )
    
    return flights
```
