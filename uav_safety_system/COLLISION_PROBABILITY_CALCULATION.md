# 한 슬롯 충돌 확률 계산 방법

## 📋 질문
> "한 슬롯에 충돌 확률을 어떻게 계산했는지 알기쉽게 설명 및 수식 작성 부탁해"

---

## 🎯 핵심 개념: Monte Carlo 방법

**Monte Carlo 시뮬레이션**이란?
- 같은 시나리오를 **수천 번 반복** 실행
- 각 실행에서 충돌 발생 여부를 확인
- 충돌 확률 = (충돌 발생 횟수) / (전체 시행 횟수)

---

## 📐 수식: 한 슬롯의 충돌 확률

### 기본 정의

**한 슬롯의 충돌 확률 (P_slot):**

```
         충돌이 발생한 시행 횟수
P_slot = ─────────────────────────
              전체 시행 횟수

         N_collision
       = ───────────
           N_total
```

**예시:**
- 1000번 시뮬레이션 실행
- 183번 충돌 발생
- P_slot = 183 / 1000 = 0.183 = 18.3%

---

## 🔬 상세 계산 과정

### Step 1: 단일 시행 (Trial) 정의

**한 번의 시행이란?**
- 한 타임슬롯(1시간, 0~60분)을 시뮬레이션
- 20대 UAV (10출항 + 10입항) 생성
- 60분 동안 모든 UAV의 움직임 추적
- 충돌 발생 여부 확인

---

### Step 2: 충돌 검사 알고리즘

#### 2.1 시간 이산화 (Time Discretization)

60분 타임슬롯을 작은 시간 간격으로 나눔:

```
시간 간격: Δt = 0.1분 = 6초

시간 포인트: t = 0, 0.1, 0.2, 0.3, ..., 59.8, 59.9, 60.0분

총 체크 포인트 수: N_time = 60 / 0.1 = 600개
```

**수식:**
```
T = {t_0, t_1, t_2, ..., t_N}
where t_i = i × Δt, i = 0, 1, 2, ..., N
```

---

#### 2.2 각 시간 포인트에서 충돌 검사

**알고리즘:**

```python
for each time point t in [0, 0.1, 0.2, ..., 60.0]:
    # 1. 현재 비행 중인 UAV 찾기
    active_UAVs = []
    for each UAV:
        if UAV.start_time ≤ t ≤ UAV.end_time:
            position = UAV.get_position(t)
            active_UAVs.append(position)
    
    # 2. 모든 UAV 쌍 간 거리 계산
    for i in range(len(active_UAVs)):
        for j in range(i+1, len(active_UAVs)):
            distance = ||position_i - position_j||
            
            # 3. 충돌 판정
            if distance < safe_distance (50m):
                return COLLISION  # 충돌 발생!
    
return NO_COLLISION  # 안전
```

---

#### 2.3 수식 표현

**시간 t에서 UAV i의 위치:**

```
p_i(t) = p_i^start + (t - t_i^start) / (t_i^end - t_i^start) × (p_i^end - p_i^start) + ε_i(t)

여기서:
- p_i^start: UAV i의 출발 위치 [x, y, z] (km)
- p_i^end:   UAV i의 도착 위치 [x, y, z] (km)
- t_i^start: UAV i의 출발 시간 (분)
- t_i^end:   UAV i의 도착 시간 (분)
- ε_i(t):    GPS 오차 ~ N(0, σ²), σ = 5m = 0.005km
```

**UAV i와 j 간의 거리:**

```
d_ij(t) = ||p_i(t) - p_j(t)||

        = √[(x_i(t) - x_j(t))² + (y_i(t) - y_j(t))² + (z_i(t) - z_j(t))²]
```

**충돌 조건:**

```
Collision at time t ⟺ ∃ i, j : d_ij(t) < d_safe

where d_safe = 50m = 0.05km
```

---

### Step 3: 한 슬롯의 충돌 여부

**슬롯 충돌 지시자 (Indicator):**

```
I_slot = 1  if ∃ t ∈ [0, 60] : d_ij(t) < d_safe for some i, j
       = 0  otherwise (안전)
```

즉, **60분 동안 단 한 번이라도 충돌 발생 → 슬롯 충돌**

---

### Step 4: Monte Carlo 확률 계산

**N번의 시행 후:**

```
시행 1: I_slot^(1) = 0 (안전)
시행 2: I_slot^(2) = 1 (충돌)
시행 3: I_slot^(3) = 0 (안전)
...
시행 N: I_slot^(N) = 1 (충돌)
```

**충돌 확률 추정:**

```
         N
        ∑ I_slot^(k)
        k=1
P_slot = ─────────────
             N

where:
- N = 1000 (총 시행 횟수)
- I_slot^(k) ∈ {0, 1} (k번째 시행의 충돌 여부)
```

## 📊 실제 계산 예시

### 예시 1: 슬롯 0 (0~60분)

**시뮬레이션 실행:**

```
Trial 1:  충돌 ✓ → I^(1) = 1
Trial 2:  안전 ✗ → I^(2) = 0
Trial 3:  충돌 ✓ → I^(3) = 1
Trial 4:  안전 ✗ → I^(4) = 0
Trial 5:  충돌 ✓ → I^(5) = 1
...
Trial 1000: 충돌 ✓ → I^(1000) = 1
```

**충돌 횟수 집계:**

```
N_collision = I^(1) + I^(2) + ... + I^(1000)
            = 1 + 0 + 1 + 0 + 1 + ... + 1
            = 188
```

**충돌 확률 계산:**

```
P_slot_0 = 188 / 1000 = 0.188 = 18.8%
```

---

### 예시 2: 모든 슬롯

**1000 trials 실행 결과:**

```
Slot 0: 188 / 1000 = 18.80%
Slot 1: 192 / 1000 = 19.20%
Slot 2: 179 / 1000 = 17.90%
Slot 3: 179 / 1000 = 17.90%
Slot 4: 187 / 1000 = 18.70%
Slot 5: 191 / 1000 = 19.10%
Slot 6: 182 / 1000 = 18.20%
Slot 7: 168 / 1000 = 16.80%
```

**평균 슬롯 충돌 확률:**

```
         8
        ∑ P_slot_i
        i=1
P_avg = ──────────
            8

      = (18.80 + 19.20 + 17.90 + 17.90 + 18.70 + 19.10 + 18.20 + 16.80) / 8
      = 146.60 / 8
      = 18.325%
      ≈ 18.32%
```

## 🎲 전체 충돌 확률 계산

### 독립 사건 확률

각 슬롯이 **독립적**이므로:

**전체 충돌 확률 (하나라도 충돌):**

```
P_overall = P(적어도 한 슬롯에서 충돌)
          = 1 - P(모든 슬롯이 안전)
          = 1 - P(slot_0 안전 AND slot_1 안전 AND ... AND slot_7 안전)
```

**독립 사건이므로:**

```
P_overall = 1 - P(slot_0 안전) × P(slot_1 안전) × ... × P(slot_7 안전)
          = 1 - (1 - P_slot_0) × (1 - P_slot_1) × ... × (1 - P_slot_7)
```

**평균 확률 사용 시:**

```
P_overall ≈ 1 - (1 - P_avg)^8
          = 1 - (1 - 0.1832)^8
          = 1 - (0.8168)^8
          = 1 - 0.1951
          = 0.8049
          = 80.49%
```

**실제 Monte Carlo 결과:**

```
1000 trials 중:
- 790 trials: 8개 슬롯 중 최소 1개 충돌
- 210 trials: 모든 슬롯 안전

P_overall = 790 / 1000 = 79.00%
```

**오차:**

```
|80.49% - 79.00%| = 1.49% ✓ (매우 작음!)
```

## 🧮 수식 요약

### 1. 위치 계산

```
p_i(t) = p_i^start + α(t) × (p_i^end - p_i^start) + ε_i(t)

where α(t) = (t - t_i^start) / (t_i^end - t_i^start)  ∈ [0, 1]
      ε_i(t) ~ N(0, σ²I), σ = 5m
```

### 2. 거리 계산

```
d_ij(t) = ||p_i(t) - p_j(t)||_2
```

### 3. 충돌 조건

```
Collision(t) ⟺ ∃ i ≠ j : d_ij(t) < d_safe
```

### 4. 슬롯 충돌

```
I_slot = max{Collision(t) : t ∈ [0, 60]}
       = 1  if any collision during [0, 60]
       = 0  otherwise
```

### 5. 슬롯 충돌 확률

```
         N
        ∑ I_slot^(k)
        k=1
P_slot = ─────────────
             N
```

### 6. 전체 충돌 확률

```
P_overall = 1 - ∏(1 - P_slot_i)
                i=1

          ≈ 1 - (1 - P_avg)^8  (평균 사용 시)
```

## ✅ 검증 방법

### 신뢰구간 계산

**Monte Carlo 표준오차:**

```
SE(P_slot) = √[P_slot × (1 - P_slot) / N]

예시: P_slot = 0.183, N = 1000
SE = √[0.183 × 0.817 / 1000]
   = √[0.1495 / 1000]
   = 0.0122
   = 1.22%
```

**95% 신뢰구간:**

```
CI_95% = P_slot ± 1.96 × SE
       = 18.3% ± 1.96 × 1.22%
       = 18.3% ± 2.4%
       = [15.9%, 20.7%]
```

```
P_slot = (충돌 발생 횟수) / (전체 시행 횟수)
       = N_collision / N_total
       = 188 / 1000
       = 0.188
       = 18.8%
```
